# kunde-xyz-produkt-a

Produktrepository fuer Kunde XYZ, Produkt A.

## Struktur
- docs/ - Quelldokumente (de-DE)
- translations/ - Uebersetzungen (je Sprache: eigene Map + Reuse)
- shared/ - Submodul: kunde-xyz-shared
- metadata/ - Metadatenuebersicht (STATUS.html)
- output/ - Generierte Ausgaben (nicht versioniert)

## Branching
- main - Stabile Inhalte
- develop - Laufende Bearbeitung
- partner/[name]_[thema] - Arbeitsbranches externer Partner
